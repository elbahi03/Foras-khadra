## 📋 نظرة عامة

صفحة **"الفرص"** لمنصة **فرص خضراء** — أكبر منصة عربية للفرص الخضراء والمناخية. تعرض هذه الصفحة قائمة من الفرص والمنح بشكل احترافي وتفاعلي، مع دعم كامل للبحث والفلترة والتصميم المتجاوب.

هذا المشروع تم تطويره كمهمة المرحلة الثانية في إطار الانتقاء لفريق تطوير الواجهات الأمامية بمنصة فرص خضراء.

---

## ✨ المميزات

- 🃏 **بطاقات الفرص** — عرض كل فرصة ببطاقة تحتوي على العنوان، النوع، الدولة، الموعد النهائي، وحالة التمويل
- 🔍 **بحث فوري (Live Search)** — البحث في عناوين الفرص في الوقت الفعلي دون إعادة تحميل الصفحة
- 🎛️ **فلترة متعددة** — تصفية الفرص حسب النوع (منحة / تدريب / مسابقة) أو حالة التمويل
- 📱 **تصميم متجاوب (Responsive)** — يعمل بشكل مثالي على الموبايل والتابلت والديسكتوب
- 🌿 **هوية بصرية ملتزمة** — ألوان المنصة (الأخضر والبرتقالي) مع دعم اتجاه RTL للعربية
- ⚡ **أداء سلس** — بدون مكتبات ثقيلة، تجربة مستخدم سريعة وانسيابية
